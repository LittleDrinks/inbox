# 采集工具分工

- 已有上游工具负责访问网站；本地脚本只补批量输入、归档和文件检查。平台入口和失败处理各自在对应 profile 维护。
- 原始分享参数原样保留，重复输入有记录，每条输入都有成功、失败或待处理结果。
- 文件存在或工具 success 不代表媒体可用，按实际格式检查。身份字段说明来源，不把输入 ID 当独立核验证据。
- 失败保留已取得的原料并准确报告；登录、验证码和风控交用户处理。重试粒度以对应 profile 为准，不为假设需求引入通用后端或恢复框架。
- 保护已有文件和人工修改；采集、读图/转录、内容消化分别验收。
- 机械错误补自动测试，语义取舍留给 agent。离线 fixture 与真实网站验证明确区分。
